# Application and third-party licensing

No project-wide open-source license has been selected for the Summit application in this package. Repository visibility by itself is not an application license grant. The supplied prototype's authorship and contribution rights require confirmation before the owner chooses an application license.

Third-party packages and assets retain their own governing terms. See:

- [Dependency inventory](DEPENDENCIES.md) and the exact [dependency lockfile](package-lock.json).
- [Third-party notices](THIRD_PARTY_NOTICES.txt) and [supplemental notices](docs/materials/supplemental-license-notices.txt).
- [Pinned dependency sources](docs/materials/dependency-inventory-with-sources.md).
- [AI and material disclosures](DISCLOSURES.md) and [artwork provenance](ARTWORK.md).

The notices are an inventory of available evidence, not a certification of rights in the supplied application. The supplemental file identifies a missing project-specific license text for the development dependency stackback 0.0.2, whose package metadata declares MIT. Optional packages for platforms not installed during the audit are listed in the lockfile; their binaries are not bundled in this source package.

The hackathon has separate [submission terms](https://hackathon.nerdy.com/terms), including rights provisions that take effect on submission. This repository package does not submit an entry or accept those terms.
